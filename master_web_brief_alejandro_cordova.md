# 1. OBJETIVO GENERAL DEL SITIO

Construir una presencia web profesional para **Alejandro Córdova** como consultor y especialista en innovación educativa, con una identidad clara en la convergencia entre:

- pedagogía;
- tecnología educativa;
- inteligencia artificial;
- formación docente;
- diseño de proyectos y soluciones educativas;
- lenguaje, lectura, escritura y pensamiento crítico como especialidad transversal.

La web debe cumplir simultáneamente cuatro funciones:

1. **Posicionamiento profesional:** comunicar con claridad quién es Alejandro, qué problemas puede resolver y por qué su perfil es diferenciador.
2. **Captación comercial:** facilitar que instituciones, equipos directivos, docentes y proyectos EdTech puedan comprender los servicios y contactar.
3. **Construcción de autoridad:** mostrar trayectoria, experiencia, proyectos, recursos, artículos y progresivamente producción académica.
4. **Plataforma de largo plazo:** permitir que la marca evolucione hacia docencia universitaria, investigación, publicaciones, conferencias y proyectos sin necesidad de reconstruir la identidad web.

# 17. RETÍCULA

## Desktop

Sistema de **12 columnas**.

La retícula debe existir, pero no debe hacerse evidente.

Objetivo:

- asimetría controlada;
- composición editorial;
- ritmo;
- orden.

Ejemplos:

- título columnas 1–7;
- imagen columnas 9–12;
- texto columnas 5–10;
- numeración en margen.

---

## Mobile

Sistema de **4 columnas**.

Márgenes sugeridos:

`20–24px`

En móvil debe priorizarse:

- legibilidad;
- ritmo vertical;
- fotografías amplias;
- numeración clara;
- composición simple.

No forzar la asimetría de escritorio.

# 27. ANIMACIONES

Las animaciones deben ser discretas.

Duración orientativa:

`150–350 ms`

Permitido:

- fade;
- desplazamiento corto;
- expansión de línea;
- cambio de estado;
- aparición de fotografía;
- microtransiciones.

Evitar:

- parallax permanente;
- objetos flotando;
- scroll-jacking;
- cursor personalizado;
- letras volando;
- efectos 3D;
- animaciones decorativas continuas.

Se permite **un único gesto visual más expresivo** en la Home.

Ejemplo:

una línea roja que se desplaza ligeramente durante la carga inicial.

# 38. RESPONSIVE

## Principio

Diseñar para móvil, no solo adaptar.

### Mobile

- lectura vertical;
- navegación simple;
- fotografías amplias;
- títulos controlados;
- botones accesibles;
- jerarquía clara.

# 39. ACCESIBILIDAD

La web debe aspirar como mínimo a buenas prácticas WCAG AA.

Considerar:

- contraste ≥ 4.5:1 para texto normal;
- tamaños legibles;
- navegación por teclado;
- estados focus visibles;
- labels de formularios;
- alt text;
- estructura semántica;
- `prefers-reduced-motion`;
- botones y enlaces claramente diferenciables.

No sacrificar accesibilidad por estética.

# 40. PERFORMANCE

El diseño debe evitar dependencia de recursos pesados.

Objetivos:

- carga rápida;
- imágenes optimizadas;
- lazy loading;
- formatos modernos;
- fuentes controladas;
- animaciones ligeras;
- JavaScript solo donde aporte valor.

La sofisticación debe provenir del diseño, no del peso técnico.

# 41. SEO Y ESTRUCTURA

- URLs claras;
- metadata;
- schema cuando proceda;
- páginas de servicio indexables;
- recursos con estructura editorial;
- Open Graph;
- sitemap.
